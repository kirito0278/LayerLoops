# LayerLoops

Vanilla HTML/CSS/JavaScript starter for the LayerLoops 3D-printing inquiry website.

## Current scope
- 43 products imported from the supplied MakerWorld JSON source
- Product catalogue + search + category filters
- My Inquiry using localStorage
- Name + phone + optional message inquiry form
- Custom printing request form
- Light neo-brutalist/editorial visual direction
- No prices, checkout, customer accounts, or technical print information
- No Vite, npm, GSAP, or runtime dependency

## Important
The current form handlers are intentionally local placeholders. The next integration step is connecting the inquiry/custom forms to the chosen submission service.
